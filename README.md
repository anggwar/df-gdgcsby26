# Build Apps with Stitch + Google AI Studio 🍜✨

### Workshop Project: "AnakKost Eats"
*From Prompt to Production: Build and ship a student food discovery app to Google Cloud Run in 90 minutes.*

---

## 0. Overview

In this hands-on workshop, you will build **AnakKost Eats** a survival food finder tailored for college students in Surabaya. 

Instead of writing backend code or wrangling complex cloud configurations, you will use:
- **Google Stitch ("Front of House"):** To visually generate and iterate responsive mobile interfaces using plain text.
- **Google AI Studio ("The Kitchen Engine"):** To wire logic, connect Gemini models with Search/Maps grounding, and store results in a browser cache.
- **Google Cloud Run:** To ship a live, production URL accessible on your smartphone in 1 click.

---

## 📚 What You'll Learn

* How to design full UI flows with natural language in **Google Stitch**.
* How to use the direct **"Build with AI Studio"** handover bridge.
* How to power dynamic discovery using **3.8 Flash** with live Google Search & Maps Grounding.
* How to prompt an AI agent to build a client-side **IndexedDB / LocalStorage cache** to save tokens.
* How to deploy a live web app directly to **Google Cloud Run**.
* How to troubleshoot UI/logic bugs using the **Screenshot Debug Protocol** without inspecting code.

---

## 🛠️ What You'll Build

* **Screen 1 (Campus Food Feed):** Campus selector dropdown, price filters ("Porsi Kuli <20rb", "Free Nasi & Es Teh"), dynamic card feed, and a "Pilihin Makan Dong Cak!" surprise button.
* **Screen 2 (Detail & AI Senior):** Interactive concierge powered by Gemini with a "Senior Kampus" persona sharing insider student survival tips in Surabaya slang (*rek*, *wareg pol*, *cak*).
* **Smart Cache Engine:** Instant loading for previously fetched warungs to keep token usage lean.
* **Production Deployment:** A live HTTPS container running on Google Cloud Run (`*.a.run.app`).

---

## 🧰 What You'll Need

* A laptop with **Google Chrome** installed.
* A Google Account logged into [Google Stitch](https://stitch.withgoogle.com/) and [Google AI Studio](https://aistudio.google.com/).
* No prior coding, Git, Docker, or command line experience required.

---

## 🎯 Workshop Goals

By the end of this 90-minute workshop, you will:
1. Understand the difference between UI design engines and logic backends.
2. Experience zero-boilerplate prompt-driven app development.
3. Deploy an authentic, working web application to Cloud Run and test it on your phone.
